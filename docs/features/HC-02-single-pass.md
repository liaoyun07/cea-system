# HC-02：液压单遍统计优化

2026-10-04，已部署并完成核心2GB/s验收。用户授权edge-b诊断和单遍统计核函数，保持HC-01完整2205周期、17原频率通道、10秒窗口、mean/population std/min/max/RMS、float64结果、参考及阈值、原SDK和核心字节/区间并集口径。无Java/API/数据库/权限/资源或通用调度变化，不增加同步等待以改变并行计算数字。

逐通道诊断旧NumPy v2：PS4的8399/13230窗口（63.48%）触发低方差回退，单通道中位49.48ms，其他压力通道18.08～20.63ms。三边缘Docker均3核/2GiB、无cpuset差异；不能据此排除瞬时CPU争用，也不把容器内共享cgroup根统计当各集群真实限流证据。

新增stats.c和native_stats.py，经镜像构建预编译，无运行时JIT。每窗口读取首个样本作锚点，单遍累计差值及差值平方，并归约min/max与非有限标志；mean=anchor+mean(delta)，var=mean(delta²)-mean(delta)²，RMS=sqrt(var+mean²)。float64累加、SIMD单线程，没有fast-math；数组布局转换和输出分配仍在计时内。没有去掉小方差准确性、输入检查或修改业务字节。

镜像多阶段编译，GCC不进入运行层。新hc02-v1应用版本和Flow r3保留v1/v2与r1/r2，数据不重做。独立全部数值、实际NPZ/评分/区间复核、预热＋三正式和原对象保留是验收条件；2GB/s以实测判定。记录见 [验证](../verification/VER-HC-02.md)。
