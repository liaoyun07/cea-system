# OFF-INDEP-01 独立卸载与配对实验

已实现、已部署并完成首轮配对实验。依赖现有 Docker 模拟引擎、四 k3s 集群、MySQL、MinIO；本批新增资源和限域权限已获用户授权。范围见 [ADR](../decisions/ADR-0031-independent-offloading.md)。

验收：五维状态顺序固定；独立三位置执行；终端串行限速上传且云边仅附加时延不同；云边总任务 CPU 额度固定；终端资源真实采样；前端终端接入中操作；整批终态后清理；旧 Flow 和无关服务不变；同 trace 的 LOCAL/RANDOM 对比与结果一致性核验。

不包含 DQN 训练或保证时延降低；不得把随机卸载称为已训练策略。

验收结果：新链路不经过普通 Flow/Execution/Worker，五任务覆盖全部目的地并自动清理；正式两组各 277/277 成功，同一到达/文件序列、六项统计输出一致，30 终端资源有采样。全终端 → 随机：平均 41.939 → 42.010 秒（基本持平），P95 161.126 → 141.184 秒，整批跨度 289.718 → 259.187 秒（降低 10.54%）。不能宣称平均时延降低或达到 40% 指标。[完整证据](../verification/VER-OFF-INDEP-01.md)。
