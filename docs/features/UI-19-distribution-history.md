# UI-19 应用分发记录默认全部与版本筛选

进入“应用分发记录”即查询当前平台工作空间全部分发记录，不自动选择第一个应用。每页20条，开始时间倒序，同时间按记录ID倒序；列表显示应用ID/版本、目标集群、状态、发起人、开始时间、耗时、源/目标镜像及错误。

上方应用版本提供“全部应用版本”和已登记版本。选择版本后只显示该版本；切换或清除筛选均回到第一页。刷新历史刷新当前条件和当前页；刷新应用仅更新可选目录。目录为空或读取失败不阻止全部历史独立加载，已删除应用的分发历史仍能在全部记录中查看。

原调用链：读取应用目录 → 默认选择第一项 → 单版本历史查询。现调用链：进入页面 → 工作空间历史分页查询；选择版本 → 复用单版本历史接口。两者均由 ImageDistributionService 校验 READ 和分页范围，再由 JdbcImageDistributionRepository 按工作空间在数据库分页，不在浏览器遍历应用聚合。

新增一个只读 GET 接口；复用原表、记录字段和类，无新增生产Java文件、表/字段、权限、缓存或中间层。分发、镜像复用、部署、普通Flow执行及应用详情历史语义不变，不涉及Kestra通用工作流逻辑。本次不增加历史删除、总数统计或自动刷新。

依赖既有分发历史与目录API。验收覆盖默认全部、多应用/多版本、数据库分页与稳定排序、筛选切换归第一页、空目录历史、请求竞态/失败恢复、权限边界及桌面/窄屏。实际测试与发布结果见 [验证](../verification/VER-UI-019-distribution-history.md)。
