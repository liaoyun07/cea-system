# UI-11 应用入口与参数契约排版

范围：仅前端排版，依赖现有应用登记、镜像上传及在线构建能力。

- 应用列表的注册、上传、构建三个按钮统一放在标题右侧，间距固定；窄屏允许自然换行。
- 参数卡片只在标题显示一次编号；字段使用名称、类型、默认值（JSON）、允许值（JSON）、数据格式、允许的数据集版本等简短标签。
- 默认值与允许值并排，必填/数据集选项集中，移除操作放在卡片右上角。窄屏字段单列。
- 三个入口共用同一参数表单；保留唯一无障碍名称、数据集约束及既有只读详情。

不改变 JSON 输入格式、默认值/choices 含义、请求体、保存/上传/构建行为或已保存应用。无新增组件、Java、字段、表、API、SPI，不涉及 Kestra 工作流语义或执行链。

验收：三个入口、桌面及390px布局、参数添加/移除/重新编号、默认值/允许值/数据集分支、原契约请求体往返单测；只发布 frontend，保留其他服务和业务数据。实际结果见[验证记录](../verification/VER-UI-011-application-layout.md)。
