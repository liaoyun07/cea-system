# HC-01：液压云边协同计算

2026-10-04，核心演示已部署、性能目标未达。复用本地完整 UCI 447 原始压缩包、三个边缘和 cloud、Application 文件协议及现有并行控制流。三边缘按传感器分工计算原采样率的 10 秒窗口均值、标准差、最小值、最大值、RMS；cloud 按周期/窗口融合标准化偏离分数并生成异常报告。来源是一套试验台，不宣称真实多站点。

离线解析全部 2205 周期为未压缩 float32 文件。PS1..PS3、PS4..PS6、其余11通道分配至 edge-a/b/c。完整正常且稳定的10周期中前5用于参考拟合、后5及其他周期用于检查；测试标签不参与参考或阈值拟合。参考样本很少，第一版是统计异常演示，不宣称部件故障分类精度。原数据无缺失，不人为插入异常。

一个新的 NumPy 轻量镜像、两个应用契约和一个新 Flow；三个边缘应用并行结束后一个云端融合任务。原工作流、服务、应用及历史保留；无需改Java生产代码、HTTP接口、数据库或权限。通用并行与文件依赖使用现有语义，不新增工作流能力。

协作计算吞吐率是实际消费/生成数组有效字节之和除以全部边缘与云端计算区间并集；完整加载后开始，包含检查/分配/计算，序列化前结束。文件SDK指标保持。另记录计算首尾跨度和流程总耗时。报告、日志、计量文件不作为业务字节。回放仅用于显式批次负载，唯一样本数保持2205，不乘epoch或加入未消费数组。

验收：独立数值对照、三组传感器和周期完整对齐、参考/检查分离、区间并集核验；实际四集群4个Job成功；一次预热和三次正式全结果保留，是否达到2GB/s由实测判定。完整验证见 [记录](../verification/VER-HC-01.md)。
