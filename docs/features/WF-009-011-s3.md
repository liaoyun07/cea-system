# S3通用控制流规格

已实现并通过验收。依据[ADR-0005](../decisions/ADR-0005-s3-control-flow.md)，本阶段不接入容器、数据集或DQN。见[实际验证记录](../verification/VER-S3-001-control-scheduling.md)。

| 工作包 | 范围 | 退出条件 |
|---|---|---|
| S3-01 | 嵌套Sequential/Parallel/Dag/If、定义与拓扑校验 | 乱序定义、汇合、分支跳过及选择重启保持；控制节点不占Worker |
| S3-02 | Flow并发limit、QUEUE/FAIL、持久FIFO | 并发提交不超限；跨版本同域；取消/失败/清理后释放无死锁 |
| S3-03 | 单Flow Cron、时区、disabled、持久游标 | 双Scheduler不重复；重启/编辑/禁用行为可验证；身份权限有效 |
| S3-04 | 故障组合、S1/S2回归、协议和文档 | 实际MySQL并发与重启测试、结构/架构/协议检查通过 |

详细字段、当前复杂度限制与消费者见[S3协议](../contracts/s3-protocol.md)。保留S2叶子重试/超时/取消和根Errors/Finally。条件选定后不可因重启再次求值；并行组失败后须等已运行兄弟收敛才进入错误处理，避免清理与正常任务串行关系失真。

实际调用链：FlowService保存修订并通过runtime同步配置；手动或Scheduler提交→ExecutionService准入→FlowExecutor解释控制树/派发叶子→Worker执行→归并/清理/提升队列。Worker不拥有运行状态，Scheduler不执行任务。

S3-01至S3-04均DONE：75项测试通过，其中52项真实MySQL集成，包含原S1/S2回归。可执行示例的true/false分支、独立Worker实际并行和独立Scheduler进程均已测试。没有以示例解析或内存模拟替代运行验证。

刻意限制：单Flow Schedule、六字段Cron、漏触发合并一次；无backfill/动态子流程/控制节点重试/嵌套errors/finally。没有验证生产容量、多机网络分区或任意外部副作用exactly-once；这些不能从本阶段验收推导出来。
