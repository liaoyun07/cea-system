# FL-HSAM-01：GFed-HSAM核心接入

## 范围与真实能力

在原FedAvg云初始化→Repeat边缘Loop训练→云聚合→云评估链上新增四个普通Application。核心包括同批四梯度的零阶/一阶平坦性优化、客户端跨轮动态正则、扰动双变量和全局扰动一致性、服务器漂移修正。真实模型和数据沿用平台，自定义epoch和轮数，不照搬作者100/500客户端与随机参与设置。

跨轮向量确有消费者：clientDrift进入本地正则、perturbationDual/globalPerturbation进入本地扰动方向、globalDrift进入聚合修正。状态集中在model.pt反馈，任务Pod保持一次性。没有新Java类/字段/数据库/API/执行引擎；无需改前后端或重启服务。新算法镜像和应用/Flow独立版本，既有镜像、定义及执行历史不覆盖。

原文中未明确的投影和扰动符号按 [协议](../contracts/gfed-hsam.md) 约定，不称逐项复现。四次前后向有额外计算成本，不承诺速度或目标精度，不把少轮数直接当完整耗时改善。

## 验收

- 独立四梯度参考值一致、扰动参数实际生效、参数恢复；零扰动无正则退化为原SGD。
- 两轮真实状态传递/序列化，客户端与服务器更新式数值一致；不混轮、不丢客户端。
- 原FedAvg/FedProx/FedCADS回归；平台MLP/CNN/CIFAR10 LeNet及数据文件协议保持。
- Flow/契约参数一一绑定、训练与测试分开准备、全客户端参与、原Repeat/Loop反馈。
- CEA新镜像/四应用/Flow发布后，实际MNIST两轮和所有模型状态/云评估复核，旧对象和20服务保持。

结果只在 [验证记录](../verification/VER-FL-HSAM-01.md) 标实际通过；不新增通用工作流能力，不涉及新的Kestra语义或Java架构索引。
