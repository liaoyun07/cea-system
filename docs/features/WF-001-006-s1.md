# WF-001–WF-006 S1功能规格

本页保留S1阶段验收语义。当前执行链、重试/取消和Worker边界已由[S2规格](WF-007-008-s2.md)扩展；S1的事务内Log不再是当前实现。

关联：S1、SEC-001基础、[ADR-0003](../decisions/ADR-0003-s1-durable-log.md)。状态见功能索引。

## 范围

Flow元数据、JSON/YAML严格解析、顺序Log任务、Inputs/Variables/Outputs、不可变修订与回滚为新版本、幂等手动执行、持久状态/日志/结果和分页查询。

## 规则

- namespace/flow/task标识稳定且合法，任务id唯一，任务数量和源文本有界；未知字段或未支持type拒绝。
- Inputs严格类型，不把数字字符串猜成数字；默认值必须满足类型，未知输入拒绝。
- Variables通过显式Binding解析，可引用inputs和其他无环变量；执行创建时冻结。
- Log消息使用严格Pebble表达式；输出message为实际渲染文本。前序任务输出可供后续消息/最终输出引用；未完成或缺失输出不能伪造成功。显式Binding在保存时检查；消息表达式中的未知/未来引用在运行时失败，不声称已做静态表达式引用分析。
- 保存携带expectedRevision：首次0；并发冲突409。旧版本不可更新；回滚复制历史定义为新revision。
- 同namespace/身份/请求键，相同原请求返回同execution；不同请求409，即使最新模板已编辑也不改变已接受请求。
- 顺序推进CREATED→RUNNING→终态；每个TaskRun有一次Attempt、时间和输出；业务渲染失败持久化错误并跳过后续。数据库错误回滚消息，不伪装业务成功。
- 持久消息与状态同事务；服务重启继续未完成步骤。S1无外部副作用，无独立Worker恢复承诺。
- namespace鉴权覆盖写/读/执行及日志、版本、结果；客户端不能指定提交者身份。

## 验收

单元测试覆盖类型、重复id、前向/未知输出、变量环、严格模板；真实MySQL验证Flyway、版本CAS、同键并发、失败回滚、双消费者、冻结版本、日志唯一、重启恢复；HTTP验证401/403/409/422及完整提交查询。

## 非目标

DAG/分支/循环/Retry/取消/外部Worker/容器执行/DQN均不在S1；支持列表之外的字段和任务显式拒绝。
