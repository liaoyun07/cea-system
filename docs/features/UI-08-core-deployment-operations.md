# UI-08 核心镜像部署与资源用量

状态：DONE（本批核心范围），验证PASS，未发布CEA。依赖UI-03/07和DEP-001/002、RES-001；用量为资源查询，不改变RES-002选址。设计见[ADR-0020](../decisions/ADR-0020-core-deployment-operations.md)。

## 授权与验收

1. 按需分发历史：原公共分发入口记录开始、完成、失败，分页授权查询；真实源/目标digest核对，失败不记成功，无旧记录回填。
2. 镜像上传：单镜像docker-save tar、受控中心仓库、文件大小/并发限制、临时目录清理；上传成功再登记不可变ApplicationVersion；真实导入与分发，不支持在线构建/断点续传。
3. 部署：完整配置回读、CAS更新、仅副本局部更新；保留非本平台字段。持续后台观察本次UID/generation，记录有效就绪耗时；失败、同名重建、变更替代、无变化、0副本及观测中断不能产生虚假达标记录。
4. 用量：读取授权集群Node与配置命名空间Pod/容器CPU、内存、采样时间/窗口。缺失或过期不可用。节点按capacity，容器百分比按明确limit；不把四个同机K3s当独立物理资源相加。
5. 前端：现有应用/分发、部署、资源页增量接入；桌面和窄屏可用，无常驻教学说明。原FedAvg/FedProx执行链回归。
