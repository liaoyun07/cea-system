3. 部署：完整配置回读、CAS更新、仅副本局部更新；保留非本平台字段。持续后台观察本次UID/generation，记录有效就绪耗时；失败、同名重建、变更替代、无变化、0副本及观测中断不能产生虚假达标记录。
