# FL-CONV-01 联邦学习达到同等准确率的效率对照

用户授权：2026-10-06。问题为相同配置FedAvg/FedCADS达到相同准确率需要多久，寻找稳定提高25%的配置。不是GB/s、平台调度加速或论文数值复现。

预定目标准确率90%。原MNIST标签排序的不重叠三分片10000/20000/30000，独立测试集10000；主网络MLP 784→128→10、三客户端每轮全参与、云初始化/聚合/评估，既有同宿主四K3s。两算法相同训练数据、batch、epochs、learning rate、初始化及shuffle seed、镜像与资源配置；FedCADS保留其辅助头/教师/历史差量，这是算法真实额外成本，不人为抵消。

筛选只用训练分片各10%确定性验证（种子314159+i），剩余54000训练、6000验证，官方test.pt不加载。共享候选lr0.01/0.03/0.1，batch128、epoch1；CADS alpha0.001、rho0.1/0.5；每条最多12轮。预筛为同一已部署fedcads-v2镜像的单进程缓存数值运算，不能作为流程端到端时间。按验证曲线选择lr0.1/rho0.1：FedAvg第10轮、CADS第7轮首次≥90%，均随后保持；rho0.5仅短暂跨线后跌落，不选。原筛选全曲线保留，不用最终测试集优化配置。

正式配置固定：batch128/epoch1/lr0.1，CADS alpha0.001/rho0.1、最多12轮；种子31/41/51/61/71，两算法同种子配对、交替先后顺序、不同时运行。两种算法各2轮预热不计正式结果。使用原完整60000训练和10000测试，初始化/训练共用seed；主网络初权重按base键逐张量核对。

计时：Execution.createdAt至首次成功evaluate.endedAt且accuracy≥90%，包含初始化、文件准备、训练/传输/聚合/评估、平台调度和等待。以评估完成作为确认达标的时间，非纯计算、非轮数替代；固定12轮全部运行和保留，达标后剩余工作不计入首次达标时间。记录首次达标后是否一直≥90%；失败、未达标保留，不赋0、不补跑替换。当前Repeat能力仅固定轮数，没有加入提前停止引擎语义。

效率提升=FedAvg平均达标时间/FedCADS平均达标时间−1；耗时下降另报，不混淆25%效率与20%耗时。以五配对均达目标、每对效率提高≥25%、CADS首次达标后保持90%作为本机“稳定达到”的严格候选判据；五样本不能推广所有随机种子或多物理设备。若失败或未达到，则不标记通过。

新增两个隔离Flow `conv01-fedavg-mnist`、`conv01-fedcads-mnist`，八个conv01-v1契约共用已发布fedcads-v2镜像；原Flow/版本/数据保持。无镜像计算核、Java/API/数据库/权限/前端、调度或配置改动，无新通用编排能力；不因试验新增Kestra模型。正式计量结果见 [验证](../verification/VER-FL-CONV-01.md)。
