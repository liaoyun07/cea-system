# OFF-SIM-DQN-01 模拟训练五维卸载模型

用户授权以模拟数据训练 DQN，让决策大致合理，减少真实容器训练耗时。本批提供离线事件模拟、实测耗时校准、Double DQN 训练、留出评估和现有网关格式导出，不改变线上调用链。

调用链：历史成功任务记录 → 校准服务/上传/完成观察耗时 → 模拟 Poisson 请求、独立上传和计算队列 → 五维观测 → 三动作 DQN → 模拟完成奖励 → 回放训练 → 验证集选权重 → 冻结模型留出测试。

新增三个 Python 文件及说明，位于 `algorithms/offloading/simulated/`。没有新增生产 Java 类、数据库表/字段、HTTP API 或基础服务；不修改普通 Flow/Kestra 语义。`environment.py` 不依赖训练库，`train_sim.py` 负责模型优化；生产仅已有 `choose` 推理格式被复用，没有给线上导入训练模块。

固定基线作实验内冻结，不能随生产策略改名或调参而变化。真实数据和训练权重保存在本地忽略目录，不将模拟任务写入真实执行表。

实际能力：已训练并导出五维模型，729 个状态组合验证纯 Python 网关推理与训练侧导出推理一致。当前线上实验仍未开放 DQN 策略，旧六维模型和服务均保持。部署属于后续真实验证批次，不因为离线训练成功而自动替换线上策略。

算法、状态、参数、数据来源与统计口径见[工具说明](../../algorithms/offloading/simulated/README.md)。实测回放存在误差，大文件决策存在边缘偏好；不宣称 CPU、内存或真实时延指标已由本模型达标。见[验证记录](../verification/VER-OFF-SIM-DQN-01.md)。
