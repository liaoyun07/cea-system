## 原则

只读分析与复制必要逻辑，不原地改旧库。模板离线转换并输出冲突报告；不制造不存在的旧版本。最终停止新增旧执行、排空或明确取消，再切换；不长期双内核运行同一请求。

ARM、多核专用优化、任务优先级与边缘离线自治没有被当前骨架实现，也不自动列为S0工作。真正上线前逐项记录已覆盖/延期/不适用和用户确认。

Git仓库归属、真实测试环境和终端协议能力在进度中跟踪，不以推测代替事实。
