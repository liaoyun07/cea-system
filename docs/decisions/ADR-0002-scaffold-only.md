# ADR-0002 首阶段仅工程和文档框架

日期：2026-09-08。状态：ACCEPTED。

## 决策

独立backend工程，Java21、Maven3.8.8至3.x；不继承旧父POM。S0仅包声明，不生成业务类，不引入Spring/数据库/容器依赖，不建立旧模型兼容层。

用POM锁定构建插件；JDK路径由验证脚本参数提供，不硬编码用户机器路径，不改变旧系统Java8环境。后续再选择受维护的Spring Boot/BOM并记录验证。

文档与实现同步维护，区分计划、实现和验证。Git仓库归属待明确，不自动git init或提交。

## 后果

S0产物不能启动服务，也没有业务测试；Maven成功仅证明结构可构建。框架验收完成后应停止，等待后续实施范围。
