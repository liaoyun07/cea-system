# VER-HC-05：常驻液压HTTP处理链

2026-10-17，用户批准方案后实施。四档探索及三次正式复测已完成；完整链路均值0.899080GB/s，未达到2GB/s。性能结论不依赖选择性删除失败记录。

## 场景与边界

持续传感器数据：三个边缘常驻应用提取均值/std/min/max/RMS，中心常驻应用对齐并融合异常评分。复用HC-02单遍C核与edge/fuse函数，完整原UCI447数据2205周期/17通道，未改采样率、算法、阈值、参考。每批64周期（末批29），35批完整回放，唯一信号385257600字节；持续压测为重复真实计算，不是新独立样本或计算结果缓存。

真实链路：k6发送原始未压缩NPZ → 三边缘HTTP解析/计算 → 特征HTTP送中心 → 三路对齐/融合 → k6读取并检查完成结果。无逐批Job、对象存储中转或最终结果持久化。初始部署/预热单列。不能将收益全部归因于省Job启动，也不能和旧4.589GB/s纯计算直接相比。

主吞吐为成功完成整批的原始float32信号字节／首批发送至最后批结束的墙钟；不加中间特征/输出字节，不扣失败和收尾。每批检查cycles、scoreSum、flagCount、inputBytes；服务端累计输入、完成数、未齐/未消费数与k6独立复算一致。资源是本批容器采样，不是全系统降低指标。
