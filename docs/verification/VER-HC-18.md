# HC-18：中心共享锁缩小的隔离对照

2026-10-18，功能与对照验证完成，**未达到2.5GB/s，也未稳定达到2GB/s**。

用户授权只修改中心共享锁范围并实测。算法、精度、输入/特征协议、完整处理链、32VU/273批每秒、单批计算并发、全部资源额度不变。代码复用State.compute维持融合串行；parts中的完整批次一直保留至成功发布，避免重复计算及reset丢失，不新增状态集合或后台队列。融合异常保留原输入、不发布成功，不自动重试。

测试重点：融合时其他批次入站/已完成结果读取可推进；计算排队不占共享锁；两份最后到达的特征并发时每批仅计算一次；重复请求/reset/未完成结果读取仍拒绝；融合失败释放计算名额并保留证据；真实32连接和175数组核验。

实验按baseline/short-lock/return三阶段，各自独立命名空间和本地证据目录，NodePort31098。每阶段10秒探针和60秒对照，候选优于本批baseline且健康才再两轮60秒。名义3GB/s不等于实际发送，报告所有漏发和失败；不通过筛选或重跑制造2.5GB/s结论。
